# AI-Powered Kanban-Based Academic Project Tracking System

## 🎯 Overview
A comprehensive SaaS platform for universities to manage academic projects using AI-powered Kanban boards. Built for students, faculty, and administrators.

## 🚀 Features
- **Role-based Authentication** (Student, Faculty, Admin)
- **AI-Powered Task Management** with OpenAI integration
- **Kanban Boards** with drag-and-drop functionality
- **Smart Deadline Predictions** and risk analysis
- **Automated Documentation Generation** (SRS, Abstract, Reports)
- **Real-time Notifications** and collaboration
- **Analytics Dashboard** with performance metrics
- **SaaS Monetization** with subscription plans

## 🛠️ Tech Stack
- **Frontend:** React.js + Vite, TailwindCSS, React DnD
- **Backend:** Node.js + Express.js, JWT Authentication
- **Database:** MongoDB with Mongoose
- **AI:** OpenAI GPT-4 API integration
- **File Storage:** Multer for document uploads
- **Payments:** Stripe integration ready

## 📁 Project Structure
```
ai-kanban-tracker/
├── backend/                 # Node.js API server
├── frontend/               # React.js application
├── docs/                   # Documentation
└── deployment/             # Deployment configurations
```

## 🏃‍♂️ Quick Start
1. Install dependencies: `npm install` in both backend and frontend
2. Set up environment variables
3. Run backend: `npm run dev` (Port 5000)
4. Run frontend: `npm run dev` (Port 3000)

## 🌐 Access URLs
- Frontend: http://localhost:3000
- Backend API: http://localhost:5000

Designed for institutions like Manav Rachna University and other academic institutions.
